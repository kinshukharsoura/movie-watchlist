# Movie & Watchlist Platform

A movie discovery app built on the TMDB API v3. Search movies, filter by
genre and minimum rating, sort by popularity, release date or rating, and
log in with a TMDB account. All filters live in the URL, so any search
can be refreshed or shared as a link.

## Tech
- React + Vite
- React Router
- TMDB API v3
- Deployed on Vercel

## Run locally
1. `git clone <repo-url>` and `cd movie-watchlist`
2. `npm install`
3. Copy `.env.example` to `.env` and add your TMDB read access token
4. `npm run dev`
